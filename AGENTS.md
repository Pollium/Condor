# Condor — agent guide

Condor is a self-hosted product analytics and session replay platform that any web app can plug
into with one script tag. pnpm monorepo with two apps:

| Package | What it is | Port |
|---|---|---|
| `packages/apps/api` (`@condor/api`) | the only backend: accounts and members, the public collector the SDK talks to (`/i/`), the workers that write sessions/events/issues, every query the web runs and the live gateway | 4100 |
| `packages/apps/web` (`@condor/web`) | the IBM Carbon web console | 5190 |
| `packages/sdk/browser` (`@condor/browser`) | the tracker: pageviews, clicks (rage/dead), errors, web vitals, custom events, identify, rrweb replay. Ships as an npm ESM module and as `condor.js`, served by the api at `/i/condor.js` | — |
| `packages/sdk/node` (`@condor/node`) | the server SDK: `track` and `identify` from any Node backend, batched per user with retries. Events land in the user's live browser session when there is one | — |
| `packages/shared/readable` (`@condor/readable`) | the HTTP/WS/queue framework: `Application`, module discovery, decorators, errors, `BaseModel`, JWT, queues, object storage | — |
| `packages/shared/contracts` (`@condor/contracts`) | every wire type and route table, one folder per domain | — |
| `packages/shared/ui` (`@condor/ui`) | the frontend plumbing: api client (`call`), `useQuery`/`useMutation`, socket channel, session and theme stores, route discovery | — |

Modules are auto-discovered from the filesystem by folder convention — there is no registry file
to edit. Modules talk to each other through services, models and `eventBus`; nothing in Condor
calls itself over HTTP.

## How data flows

```
browser ──SDK──▶ api /i/batch ──enrich──▶ BullMQ condor-ingest-batch ──▶ tracking worker ──▶ Postgres
        ──SDK──▶ api /i/replay ──gzip──▶ S3 replays/<project>/<session>/<seq>.json.gz
                                  └─────▶ BullMQ condor-ingest-replay ──▶ ReplayChunk rows
web ──/api──▶ api (+ ws /api/live)   ──/i──▶ api
```

- One public origin serves everything. In dev the web's Vite proxy maps `/api` → 4100 (stripped,
  with the websocket) and `/i` → 4100 (kept). In production `deploy/nginx.conf` does the same, so
  the SDK host is just the console's origin.
- The collector never writes a table: it enqueues, and the `tracking` workers write. Replay chunks
  go to S3 before their row exists.
- A server batch (no `sessionId`, a `userId`) reuses the person that already carries that `userId`
  and joins their session if it ended less than `SESSION_GAP_MS` ago, so backend events show up in the
  replay timeline and count toward conversion. The collector never drops a server batch as a bot.
- Sessions and people are created by the worker on the first event it sees. The session id is
  generated by the SDK (uuid), so it is stable across batches and replay chunks.
- `eventBus` is Redis pub/sub on `condor:events`, so every api replica hears it (the collector's
  project cache drops a key on `project.changed`).
- The web authenticates with the JWT the api signs (`JWT_SECRET`). Roles: `owner` (members +
  everything), `admin` (apps, settings, issues), `viewer` (read only), read from the `User` row on
  every request.

## Commands

```
pnpm infra                                    # Postgres :5442, Redis :6389, S3 (rustfs) :9010
pnpm dev                                      # infra + api, SDK watch build and web
pnpm --filter @condor/api test                # Vitest, inside the package
pnpm typecheck && pnpm lint && pnpm test      # the gates a change must pass
docker compose up -d --build                  # the full self-hosted stack on :8080
```

## Things that will otherwise burn an hour

- **Vitest runs inside the package.** Running it from the repo root picks up every package's config
  at once. `cd packages/apps/api && npx vitest run`.
- **Never `tsc -b` in the api.** It sets no `outDir`; typecheck with `tsc --noEmit`.
  `tsc -b` is correct in `packages/apps/web` (its `build` script) and rebuilds the contracts'
  declarations the web reads from `packages/shared/contracts/dist`.
- **After editing contracts**, clear the api's typia cache
  (`rm -rf packages/apps/api/node_modules/.cache/unplugin_typia`) and restart the web dev server.
- **`BaseModel` ids default to Postgres 18's `uuidv7()`.** The compose image is `postgres:18-alpine`;
  an older Postgres fails at `synchronize`.
- **The SDK posts `text/plain`.** `navigator.sendBeacon` and a no-preflight `fetch` cannot send
  `application/json` cross-origin, so the api registers a `text/plain` parser that reads JSON.

Code style: 4-space indent, single quotes, semicolons, `if(` / `}else{` / `try{` with no space,
`interface Name{`, private `#fields`, no comments, English identifiers. All web copy is Spanish.
